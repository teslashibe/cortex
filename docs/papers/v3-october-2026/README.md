# Cortex academic manuscript

This manuscript presents the memory model, retrieval method, selective
classification experiment, conditional proofs, limitations, and conclusion.
Software identifiers belong in the reproducibility manifest, not the scientific
narrative. The LaTeX source is `main.tex`; bibliography and measured tables are
separate source files.

The propositions and theorems concern an explicitly assumed transition system.
They do not prove semantic truth, retrieval accuracy, or implementation correctness.
The manuscript is a research draft and has not been peer reviewed.

The public probe includes a case-level grading audit. Two earlier decisions
changed in opposite directions, leaving the aggregate score unchanged. See the
erratum linked from the historical paper. Real-session inputs, review labels,
per-example results, and trained model artifacts remain private.

Build locally with XeLaTeX and BibTeX, or open this directory in the Codex LaTeX
editor. `manifest.json` records the exact implementation and artifact hashes.
