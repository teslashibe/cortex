\noindent The following replay measurements use the historical source filter and partition graph. The broader audit below qualifies both training and evaluation; these scores are regression diagnostics, with no independent human-conversation interpretation.

\subsection{Source and related-project audit}
\label{sec:source-audit}
The source audit excluded 168 messages containing known machine or mixed-authorship material. In the 3,585-example dual-model dataset, 116 accepted natural candidates were affected: 35 training, 76 development, and five previously tested candidates. The 1,592 original synthetic examples are separate. The remaining 1,877 natural candidates retain provisional labels.

Forty of 123 inspected sessions named more than one known repository in their working-directory metadata. Conservative grouping found 16 connected components. One component contained 1,700 natural candidates across all three original partitions. The original directory-based partitions therefore cannot substantiate independent-project transfer. An additional inventory of the same file-based stores contained 79 new message identifiers but no new independent connected component. These additional messages were reserved outside the present fit. This inventory did not exhaust every local application store; subsequent collection from additional history databases and desktop session stores is separate from this frozen experiment.

The audit also traced the earlier 3,032-candidate corpus used in the historical tables below. It found 176 affected authorship candidates, including nine in that corpus's test partition, and 2,760 candidates in a connected component spanning all original partitions. These are different corpora and denominators. Historical metrics are preserved; removing contaminated evaluation rows alone would not repair affected training.

\subsection{Historical replay comparison}
The final library contains 75 matched primary sources from four source components in the original graph. Its retention distribution is 57 temporary, six durable, eleven ignored, and one uncertain candidate in each paired arm. The typed primaries include 53 projects, five facts, three preferences, one routine, and one behavior; no relationship example survived. These imbalances limit any class-specific conclusion.

The fitting pools contain 317 earlier and 168 newer natural candidates, plus 1,063 original synthetic training examples. The main development evaluation has 24 older and 18 newer candidates, with 22 and 18 typed candidates respectively. Related-project diagnostics contain another 269 older and 851 newer candidates; they are never counted as independent transfer. The synthetic development cohort contains 262 examples.

The older cohort contains 19 durable, three temporary, and two ignored candidates. Its types are 18 routines, two facts, and two projects. The newer cohort contains 14 durable and four temporary candidates, with nine routines, six preferences, and three projects. No uncertain label appears in either cohort. These small, uneven supports leave several classes unevaluated and limit the interpretation of macro-F1. Full aggregate confusion matrices, calibration measures, and related-project diagnostics accompany the manuscript.

The two contributing generation batches attempted 625 source pairs and produced 1,119 structurally valid utterances. Thirty-two pairs failed generation, 67 returned no recombination, and 105 invalid generation responses were recorded across attempts. One annotation batch failed, leaving sixteen examples without complete review. Model agreement and semantic checks retained 123 paired sources before local source, duplicate, and connected-partition checks. Recorded generation and review responses returned 1,399,449 tokens, including rejected and invalid outputs. Usage for attempts without a returned usage record is unknown. A verified monetary charge was not returned.

The earlier variable-padding experiment is preserved as a qualified diagnostic: recombination improved mean older-cohort macro-F1 from 0.532 to 0.547 relative to ordinary mixed training, while newer-cohort macro-F1 fell from 0.481 to 0.408 and accepted disagreement rose from 17.5\% to 25.8\%. \subsection{Serving and persistence checks}
A predetermined seed-17 recombination artifact was exported solely for interface verification, without selecting the highest-scoring run. On 32 candidate fixtures, the Python service and current Go API reproduced saved probabilities with a maximum absolute difference of $6.78\cdot10^{-7}$. Source hashes and the abstention rule matched. Twelve invalid-request or source-lifecycle checks returned rejection, covering owner mismatch, deleted and archived evidence, invalid spans, incompatible model or policy identifiers, empty requests, duplicate identifiers, and input limits. The isolated PostgreSQL store contained zero memories and zero training events before and after classification. These checks verify the advisory contract and do not measure semantic memory quality.

The current software commit also passed 86 Go tests with the race detector and PostgreSQL 17, with no skipped tests, plus static analysis and builds. Both database checks used disposable local containers. No private observation or generated training example was written to a production store.
