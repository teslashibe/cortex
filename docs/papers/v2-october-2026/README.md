# October 2026 paper

[Read the PDF](paper.pdf) or edit [the LaTeX source](main.tex).

Paper version 2 describes [Cortex v1.0.1](https://github.com/teslashibe/cortex/releases/tag/v1.0.1),
code commit `b8bf2da1e06c2e2e73f8b8fbff08fa843327f551`.
It reports a small local development diagnostic, including extraction omissions.
The results are not a public-benchmark score or a comparison with competing systems.

Build with `xelatex main.tex` twice, or open this directory in Codex's LaTeX editor.
The evaluation corpus, raw outputs and database exports are deliberately not
included in the repository. The paper contains only aggregate results and methodology.
