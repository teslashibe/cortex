# March 2026 paper

This is the unchanged original paper, **Applying Sleep-Dependent Memory
Consolidation to Agent Architecture**, by Brendan Playford, dated March 2026.
The supplied PDF was created on 20 March 2026. It is retained as paper version 1.

The paper describes the earlier architecture and includes proposed mechanisms
that are not implemented in Cortex v1.0.1. Its claims and references have not been
retrospectively rewritten. It states that it has no benchmark results.

Paper versions are independent of software release tags. See the
[October paper](../v2-october-2026/paper.pdf) for the current implementation and
its measured limitations.
