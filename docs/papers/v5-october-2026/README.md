# Academic manuscript, revision 5

Cortex: Provenance-Preserving Memory with Selective Classification for Language Agents

This version connects the design to complementary learning systems and sleep
research, describes the source-checked evidence reader, and reports a larger
private classification study and a separate public evaluation.

Biological findings motivate hypotheses. The software does not simulate REM
sleep. Its conditional proofs establish properties of the stated abstract
machine and do not establish semantic accuracy or formal verification.

The manifest identifies the implementation and final artifact hashes. Only
aggregate measurements are published. Conversations, annotations, per-example
outputs, model weights, and database exports stay private. Earlier paper
versions remain unchanged.

Build with `xelatex main.tex`, `bibtex main`, and two further `xelatex main.tex`
passes. The release PDF is `paper.pdf`.
