# Academic manuscript, revision 7

Cortex: Sleep-Inspired Memory Consolidation for Language Agents

This edition reports a controlled development experiment with source-grounded
paraphrases and recombined training examples. It includes twelve chronological
adaptation runs across three seeds, their three common initial checkpoints, and
three pooled ordinary-training references. Neither generated condition meets
the joint development improvement criteria. No trained classifier is promoted.

Source audits identify machine or mixed authorship in earlier user-role records
and related-project overlap across directory-based partitions. Historical scores
remain available with those qualifications. The corrected comparison excludes
detected machine context, holds out connected source components, and fixes
training presentations, update counts, and padded tensor dimensions. Its main
development cohorts contain only 24 older and 18 newer candidates. All labels
remain provisional, and generation resources are additional costs.

The paper separates classification agreement from factual retention and
unsupported-memory creation. Its nine propositions and two theorems establish
conditional software properties, including recorded-lineage separation and
matched replay schedules. They do not prove a learning benefit or biological
fidelity. Independent human judgments and downstream confirmation remain required.

A separate local check exercises a predetermined model artifact through the
Python service and Go API on 32 candidates. Twelve invalid-request and lifecycle
checks reject the inputs, with no memory or training-event writes. The current
code also passes 86 PostgreSQL-backed Go tests with the race detector. These
software checks are distinct from the unsuccessful comparative quality criteria.

The manuscript preserves the earlier public retrieval results and separately
sourced platform context. The final evaluation protocol specifies the remaining
work before making comparative claims. The expanded local-history and historical
email collection begun after this experiment is outside its frozen dataset.

The public artifacts contain aggregate results only:

- `learning_results.json`: replay outcomes, budgets, controls, and source audits
- `learning_diagnostics.json`: class supports, confusion matrices, and calibration
- `serving_validation.json`: model/API contract and software-check results
- `results.json` and `classifier_analysis.json`: qualified historical measurements
- `manifest.json`: implementation identity, protocol hashes, and artifact hashes

Private conversations, email, annotations, per-example outputs, provider
responses, experiment scripts, and weights remain outside Git. Prior paper
editions are unchanged. Paper revisions are independent of software releases;
the current published software release remains v1.4.0.

Build with `xelatex main.tex`, `bibtex main`, and further `xelatex main.tex`
passes until references stabilize. The checked PDF is `paper.pdf`.
