# Cortex v1.5.0: interim research milestone

This release packages the completed engineering changes and research record as
of October 22, 2026. It adds host-checked consolidation of explicitly selected
sources and improved classifier diagnostics, and includes paper revision 8.
The research program is paused at this checkpoint. Its comparative quality
target has not been met, and learned classifiers remain advisory.

## Code changes since v1.4.0

- `ConsolidateSelected` accepts exact observation and memory selections. Its
  required host guard checks current permissions before inference and again
  inside the atomic memory commit. Empty memory selection supplies no existing
  memory context. The host owns authentication and source selection.
- The selected path makes one model call, with no automatic splitting,
  truncation, format repair, or provider retry. Changed or rejected sources
  leave observations pending. Saved outcomes support reconciliation after a
  cancellation or lost response.
- Classifier tools add optional class balancing, per-class confusion and
  calibration diagnostics, training-majority baselines, and separate reports
  for human, teacher, and synthetic labels. Defaults remain unweighted.

The database schema is unchanged. Existing `Observe`, `Recall`, and `Consolidate`
operations retain their behavior. Classification does not write memories,
suppress observations, or authorize forgetting.

## Research checkpoint

Paper revision 8, *Cortex: Sleep-Inspired Memory Consolidation for Language
Agents*, includes the LaTeX source, a 33-page PDF, aggregate measurements, and
an artifact manifest. Earlier paper editions remain unchanged.

Source audits found automation and mixed-provenance records in data previously
marked with the user role, plus related projects across earlier partitions.
The earlier scores are preserved and qualified as historical diagnostics.
After conservative exclusion and copy screening, the corrected study contains
5,548 training candidates and 424 development candidates. Training forms one
connected source component; development has thirty. All labels are provisional
model judgments, with zero independent human reviews.

Twenty-two pairs of frozen-encoder classification heads compare source counts
and class balancing:

| Full-source result | Unweighted | Class-balanced |
| --- | --- | --- |
| Retention macro-F1 | 0.393 | 0.372 |
| Type macro-F1 across six configured classes | 0.256 | 0.255 |
| Durable examples recovered | 0/14 | 5/14 |
| Joint acceptance coverage | 151/424 | 28/424 |
| Provisional-label disagreements among accepted predictions | 14/151 | 7/28 |

The balanced model predicts durable for seventy examples, with sixty-five
disagreements. Type evaluation has no behavior or relationship examples and
only one routine. Development calibration is selected on the same set used
for these selective scores. These limitations prevent promoting either model.

Twelve adaptation runs show that retaining synthetic training examples reduces
forgetting on the designed classification tasks. Generated replay does not meet
the joint improvement criteria on the qualified historical development cohorts.
These classification scores do not measure factual knowledge retention.

Thirty fictional memory episodes show that original-source retrieval can conceal
information omitted by learned source selection. Six stale-current flags arose
where the correcting observation was withheld. A separate assertion-boundary
study retains 19/20 required phase-level claims with 0/28 forbidden claims
detected. Eight historical-ingestion episodes retain 16/16 required claims with
0/12 forbidden claims detected. These are small model-judged diagnostics over
repeated fictional fixtures, not evidence of safety on natural conversations.

The earlier sixty-case public retrieval study remains 47/60 reference-aligned
answers for the source-checked reader, including eleven conditional answers,
versus 45/60 for the direct reader. The call budgets differ and the result does
not establish a reliable advantage. No matched platform comparison is complete.

The sleep analogy motivates source capture, offline integration, grounded replay,
and controlled recombination. Cortex does not simulate REM physiology. The
paper's ten propositions and two theorems establish conditional software
properties; they do not prove semantic truth or learning convergence.

## Validation and downloads

Release validation passed 86 Go tests with PostgreSQL 17 and the race detector,
with no skipped tests; eleven classifier and three embedding Python tests;
`go vet`; builds; vulnerability checks; and Git-history and working-tree secret
scans. The paper passed XeLaTeX, BibTeX, the desktop compiler, and visual review.
These checks cover software contracts, not general semantic quality.

Downloads include command archives for macOS and Linux on amd64/arm64 and
Windows amd64, the paper PDF, LaTeX source, manifest, and SHA256 checksums.
Command archives include the license, dependency notices, and build identity.
Optional Python dependencies and model weights are installed separately.

Private conversations, email, datasets, annotations, per-example outputs,
provider responses, experiment scripts, and weights remain outside GitHub.
Email has not entered these training runs. No new inference or training runs
were needed to prepare this release.

## Remaining work

Independent human review and better minority-class coverage are needed before
further quality claims. The next development experiment should compare encoder
adaptation and loss weighting against the frozen corrected-source baselines.
Any selected design still needs fresh conversation groups, matched ordinary and
repeated-example controls, downstream/API checks, and no increase in unsupported
memories. Reserved natural confirmation records and 421 unexamined public
LongMemEval-S cases remain untouched. Research stays paused until resumed.
